Cleanup After Demo Remove All Resources — Avoid Surprise Charges
⚠️ Always use stop not delete during demos — stopping keeps your data. Use delete only for full cleanup.
🖥 Delete VM
gcloud compute instances delete paperflow-vm --zone=us-central1-a 📋
📍 Delete Static IP
gcloud compute addresses delete paperflow-ip --region=us-central1 📋
🗑 Delete Storage Bucket
gcloud storage rm -r gs://paperflow-pdfs-demo 📋
🔐 Delete Secrets
gcloud secrets delete OPENAI_API_KEY 📋
gcloud secrets delete POSTGRES_PASSWORD 📋
🔥 Delete Firewall Rules
gcloud compute firewall-rules delete allow-paperflow-frontend 📋
gcloud compute firewall-rules delete allow-paperflow-api 📋
✅ Verify Nothing Remains
gcloud compute instances list📋
gcloud compute addresses list📋
gcloud secrets list📋
Troubleshooting Common Issues & Quick Fixes
ProblemDiagnose CommandFix
VM won't startgcloud compute instances describe paperflow-vm --zone=us-central1-aCheck quota in us-central1
Can't reach :3000 or :8000gcloud compute firewall-rules listRe-run firewall-rules create commands
Container keeps restartingdocker compose logs gateway --tail 50Check OPENAI_API_KEY is set in .env
Secret not foundgcloud secrets listRe-run secret create command
Permission denied on bucketgcloud projects get-iam-policy YOUR_PROJECT_IDRe-run storage IAM binding command
Static IP changedgcloud compute addresses describe paperflow-ip --region=us-central1You used delete instead of stop
